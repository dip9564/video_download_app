# 🎬 Video Downloader (Streamlit App)

👉 🌐 Live Demo:
[view live app](https://video-download-app.streamlit.app￼)

A simple and interactive web app built using Streamlit that allows users to download YouTube videos or audio in different formats and qualities.

⸻

🚀 Features

* 📥 Download videos (MP4)
* 🎚️ Select video quality (Best, 1080p, 720p, 480p)
* 🎥 Video preview inside the app
* 📱 Works on desktop and mobile (local network)
* 💡 Clean and beginner-friendly UI

⸻

🛠️ Tech Stack

* Python
* Streamlit
* yt-dlp
* FFmpeg (for MP3 conversion)

⸻

📦 Installation

1. Clone the repository
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name

2. Install dependencies
pip install -r requirements.txt

4. Run the app
streamlit run app.py

🌐 Deployment

This app is deployed using Streamlit Community Cloud.

👉 Live Link:
https://video-download-app.streamlit.app

⸻

⚠️ Limitations

* ❌ YouTube may block downloads on cloud (HTTP 403 error)
* ❌ MP3 conversion may not work online (FFmpeg not available)
* ⚠️ Large video downloads may be slow or restricted
* ⚠️ Works best locally for full functionality
